현재 개체 수를 기준으로 ‘다음 1세대’의 변화를 계산합니다.

🟠 J자형 — 자원 제한 없음+

순증가량 = (출생률 − 자연 사망률) × 현재 개체 수
🟢 S자형 — 자원 제한 있음+
출생+자연 사망−환경저항에 따른 추가 사망−다음 세대 순증가+
순증가량 = (출생률 − 사망률) × N × (1 − N / K)

🧠 곡선의 모양이 결정되는 원리

01. J자형 · 양의 되먹임

자원이 충분하다고 가정하면 개체 수가 늘수록 새로 태어나는 개체 수도 커집니다. 매 세대 같은 비율로 증가하므로 증가하는 개체의 절대 수가 계속 커져 그래프가 위로 가파르게 휘어집니다.

개체 수 ↑ → 출생 개체 수 ↑ → 다음 세대 더 빠른 증가
02. S자형 · 환경저항과 환경수용력

처음에는 J자처럼 빠르게 늘지만, 개체가 많아지면 먹이·공간 등을 둘러싼 경쟁이 커집니다. 이 실험에서는 경쟁에 의한 추가 사망이 증가하도록 설정했습니다. 개체 수가 K의 절반 부근에서 순증가량이 가장 크고, K에 가까워질수록 출생과 전체 사망이 균형을 이루어 성장 속도가 0에 가까워집니다.

개체 수 ↑ → 자원 경쟁 ↑ → 순증가량 ↓ → K 부근 안정
🎯 마지막 확인 문제

S자형은 왜 평평해질까?

개체군이 환경수용력 K에 가까워질 때 가장 알맞은 설명을 골라 보세요.

수업용 단순화 모형입니다. 각 세대의 개체 수·출생·사망은 기대값이므로 소수점으로 표시됩니다. 실제 개체군에는 이입·이출, 시간 지연, 환경 변화, 자원 경쟁으로 인한 출생률 감소 등도 작용합니다. J자형 성장도 현실에서 무한히 유지되지는 않습니다.
